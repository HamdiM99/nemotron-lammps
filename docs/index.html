    What the model asked for, what the code answered

    The model only has four bounded tools. It picks parameters; the code generates the LAMMPS input, rejects anything out of bounds and only allows the full run after a short run has succeeded.

      Scope

      What this measurement does not tell you

      • Classical potential: the value depends on the chosen potential and does not replace an ab initio calculation.
      • Linear regime only: strain is capped at 5%, so the sheet stretches but does not break.
      • No electronic properties and no thermal conductivity.
      • Molecular-dynamics strain rate, far higher than in a real test.
      • A single random draw of vacancies; stress uses the conventional thickness of Å.
